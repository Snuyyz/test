# Defending the Republic: The Democrats, 2014-2026

A standalone mod for *Social Democracy: An Alternate History* (built with
[dendrynexus](https://github.com/originn0/dendrynexus), the same toolchain as the base game).
You play the Democratic Party from January 2014 to the November 2026 midterms.
Each turn is one quarter and you get two actions. The goal is to keep American
democracy standing against the MAGA right, the organized far-right, the insurgent
far-left, a pandemic, and your own factional fights.

## Build

    npm install
    npx dendrynexus make-html      # outputs out/game.json and out/html/

Open `out/html/index.html` through a local web server
(`python3 -m http.server -d out/html`), or copy `out/game.json` somewhere public and
paste its URL into the base game's **Mods** screen.

## Playtest bot

    node tools/playtest.js 100 random    # random player
    node tools/playtest.js 100 pass      # does nothing (should lose)
    node tools/playtest.js 40  greedy    # 1-ply optimizer

## Layout

    source/scenes/root.scene.dry          start screen + ALL starting qualities
    source/scenes/post_event.scene.dry    turn advance, structural pressures, end conditions
    source/scenes/main.scene.dry          main menu
    source/scenes/party/*.dry             party actions (tag: party_action)
    source/scenes/govt/*.dry              government actions (tag: govt_action)
    source/scenes/events/*.dry            GENERATED by tools/gen_events.py - edit the .py, not these
    source/scenes/game_over.scene.dry     endings
    tools/gen_events.py                   event + election table (edit here, then re-run)

## How the model works

* **Elections** use the historical two-party vote as a baseline
  (`ELECTIONS` table in `tools/gen_events.py`). Your play adds a modifier
  (`pop_mod`, plus enthusiasm / unity / stability terms) that is capped and decays
  each quarter. Presidential elections need a vote share above an Electoral College
  threshold (51.5 in 2016, 52.0 in 2020, 50.5 in 2024).
* **Stability** (0-100) is the loss condition. Each quarter it erodes from background
  polarization, MAGA strength (worse when the right holds the White House), and
  extremism on either flank, and it recovers from your actions. At 10 or below the
  republic collapses. Repair speed is capped per quarter.
* **Branches:** primaries in 2016 / 2020 / 2024 and the election results change who
  holds the White House, with fallback events for the alternate-history branches.

## Known limitations (v0.1)

* The 2026 baseline in `ELECTIONS` is **provisional**: it was set from early
  post-election reporting (Democrats winning both chambers, Senate counts still
  being finalized as of Nov 8, 2026). Update house/senate/vote-share when final.
* Balance was tuned only with bots. It needs human playtesting.
* Alt-history branches are thinner than the main path. No images or music yet.
* Factions exist as numbers but do not yet trigger their own events
  (splits, walkouts, third-party threats).
